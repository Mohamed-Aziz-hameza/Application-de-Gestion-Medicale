============================================================
  POSTMAN API TESTING GUIDE - App Médicale
============================================================

Base URL: http://localhost:8080

============================================================
1. REGISTER A MEDECIN
============================================================
Method:  POST
URL:     http://localhost:8080/api/auth/register/medecin
Auth:    None
Headers: Content-Type: application/json
Body (raw JSON):
{
  "nom": "Dupont",
  "prenom": "Jean",
  "email": "jean.dupont@mail.com",
  "motDePasse": "password123",
  "specialite": "Cardiologie"
}

Expected Response (200):
{
  "message": "Inscription réussie. Votre compte est en attente d'activation par un administrateur."
}

============================================================

============================================================
3. LOGIN AS ADMIN (or MEDECIN) — returns JWT
============================================================
Method:  POST
URL:     http://localhost:8080/api/auth/login
Auth:    None
Headers: Content-Type: application/json
Body (raw JSON):
{
  "nom": "Admin",
  "prenom": "Super",
  "id": 1,
  "motDePasse": "adminpassword"
}

NOTE: Replace nom, prenom, id, motDePasse with your actual
      Administrateur or Medecin data from the database.
      The account must have statusCompte_id = 1 (active).

Expected Response (200):
{
  "token": "eyJhbGciOiJIUzI1NiJ9...",
  "type": "Bearer",
  "id": 1,
  "nom": "Admin",
  "prenom": "Super",
  "email": "admin@mail.com",
  "role": "ROLE_ADMIN",
  "message": "Connexion réussie"
}

>>> COPY THE "token" VALUE — you will need it for admin endpoints <<<

============================================================
4. LOGIN AS PATIENT — Step 1 (sends OTP to email)
============================================================
Method:  POST
URL:     http://localhost:8080/api/auth/login/patient
Auth:    None
Headers: Content-Type: application/json
Body (raw JSON):
{
  "email": "marie.martin@mail.com",
  "motDePasse": "password123"
}

NOTE: The patient account must be active (statusCompte_id = 1).
      An admin must activate it first.

Expected Response (200):
{
  "message": "Un code OTP a été envoyé à votre adresse email"
}

============================================================
5. LOGIN AS PATIENT — Step 2 (verify OTP, get JWT)
============================================================
Method:  POST
URL:     http://localhost:8080/api/auth/login/patient/verify-otp
Auth:    None
Headers: Content-Type: application/json
Body (raw JSON):
{
  "email": "marie.martin@mail.com",
  "codeOtp": "123456"
}

NOTE: Replace "123456" with the actual OTP from the email.
      OTP is valid for 10 minutes and can be used only once.

Expected Response (200):
{
  "token": "eyJhbGciOiJIUzI1NiJ9...",
  "type": "Bearer",
  "id": 3,
  "nom": "Martin",
  "prenom": "Marie",
  "email": "marie.martin@mail.com",
  "role": "ROLE_PATIENT",
  "message": "Connexion réussie"
}

============================================================
6. ADMIN — ACTIVATE A USER ACCOUNT
============================================================
Method:  PUT
URL:     http://localhost:8080/api/admin/activate/2
Auth:    Bearer Token
Headers: Content-Type: application/json

In Postman:
  → Go to "Authorization" tab
  → Type: Bearer Token
  → Token: paste the admin JWT token from step 3

NOTE: Replace "2" in the URL with the actual utilisateur id
      you want to activate.

Expected Response (200):
{
  "message": "Compte activé avec succès pour Dupont Jean"
}

============================================================
  ERROR RESPONSES YOU MAY SEE
============================================================
- {"message": "Identifiants invalides"}           → wrong nom/prenom/id
- {"message": "Mot de passe incorrect"}            → wrong password
- {"message": "Votre compte est désactivé..."}     → account not activated
- {"message": "Cet email est déjà utilisé"}        → duplicate email
- {"message": "Code OTP invalide, expiré ou déjà utilisé"} → bad OTP
- {"message": "Accès refusé"}                      → not admin role
